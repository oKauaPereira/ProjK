📱 Projeto FlutterFlow - Consulta de CEP
📌 Descrição

Este é um aplicativo desenvolvido no FlutterFlow que permite consultar informações de endereço a partir de um CEP utilizando a API pública do ViaCEP. O app conta com uma navegação simples e intuitiva usando um menu lateral (Drawer).

🚀 Funcionalidades
🔍 Consulta de endereço por CEP
🌐 Integração com API do ViaCEP
📋 Exibição de dados como:
Logradouro
Bairro
Cidade
Estado
📱 Interface responsiva
📂 Navegação por menu lateral (Drawer)
🛠️ Tecnologias Utilizadas
FlutterFlow
Flutter (gerado pelo FlutterFlow)
API REST (ViaCEP)
🔗 API Utilizada

ViaCEP
Endpoint:

https://viacep.com.br/ws/{cep}/json/
